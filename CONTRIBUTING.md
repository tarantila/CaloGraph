# Contributing to CaloGraph

Contributions are welcome. Bug reports, documentation improvements, tests, and
focused code changes all help the project.

Participation in the CaloGraph community is subject to the
[Code of Conduct](CODE_OF_CONDUCT.md). Keep discussions respectful, protect
personal health data, and use synthetic or thoroughly redacted examples.

## Development workflow

1. Open an issue or discussion before starting a broad architectural change.
2. Keep a pull request focused and explain its user-visible and security impact.
3. Add or update tests for behavioral changes.
4. Run the backend, frontend, and relevant container checks documented in the
   [README](README.md).
5. Never include real health records, credentials, session values, invitation
   links, API tokens, database dumps, or production logs.

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md), not
through a public issue.
